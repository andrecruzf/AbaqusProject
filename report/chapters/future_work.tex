\chapter{Future Work}\label{chap:future_work}

The next steps should focus on turning the verified workflow into a validated
numerical forming limit campaign.

\begin{enumerate}
  \item \textbf{Extend the mesh analysis.} The current
  $\Delta t_\mathrm{MS}=\SI{1e-6}{\second}$ and $f_\mathrm{MR}=1.41$ setting is
  only a working choice for the \texttt{W100} reference case. The mesh study
  should be extended beyond the global refinement factor, since the parametrised
  mesh also exposes local seed sizes, transition regions, dome sizing, and
  growth factors.

  \item \textbf{Run the numerical campaign.} The simulations should be extended
  from the reference cases to the specimen widths, sheet thicknesses, punch
  diameters, and material orientations used experimentally. The AA5182
  surrogate material constants and the contact coefficients should then be
  replaced by calibrated AA5754 and friction data.

  \item \textbf{Continue the Min Stoughton evaluation.} The criterion should be
  tested on more experimental data and checked across different punch
  diameters. This is needed to understand whether its behaviour remains stable
  when the strain field and fitting window change with punch geometry.

  \item \textbf{Improve numerical post processing.} The necking onset detection
  for the numerical framework should be further tested against strain paths,
  force drops, element deletion, and visual movie inspection. This is required
  before the numerical FLC extraction can be treated as robust.

  \item \textbf{Move toward a local application.} The Streamlit interface is
  useful for the current workflow, but a full local application would be better
  suited for large result folders, direct file access, job synchronisation, and
  responsive plot review.
\end{enumerate}
